## Decision

The product contains substantial domain services, but the main user journey is **not reliable end to end**. Persisted analysis dates break extension package preparation; the web review cannot normally obtain its required approval ticket; sidebar handlers overwrite one another; the prepare response is not the canonical autofill payload; uploads do not actually attach a resume. Web discovery has no configured adapters, dashboard projections lose real projects, and one MCP job resource calls its service incorrectly. Resume parsing, field preservation, template choice, editing and truthful score presentation also require repair.

These conclusions use source tracing, new defect reproductions, actual disposable PostgreSQL/HTTP integration tests, real Chromium DOM mutation, and actual generated PDFs. A button, declared capability, historical completion claim, synthetic adapter, or passing defect-characterization test is not evidence of a working platform integration.
