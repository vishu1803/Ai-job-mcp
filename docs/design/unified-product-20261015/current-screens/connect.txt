SAFETY KERNEL
Two-Phase Write Safety & Stopping Protocol

AI assistants are strictly prohibited from making direct modifications to your GitHub repositories or publishing unauthorized artifacts. Career Hub enforces a cryptographically signed two-phase approval protocol:

1. Proposal Generation

AI calls propose_project_improvement. Server generates a validated diff and signed Action Approval Ticket.

2. Human Diff Review

You inspect the exact file modifications in your chat interface or web workspace.

3. Explicit Confirmation

Only after your explicit confirmation, AI calls confirm_and_create_pr with your ticket ID.

4. Isolated Draft PR

Server validates HEAD SHA, creates branch feat/career-hub-*, and opens a Draft Pull Request.
